# 软件图标目录

请将软件的品牌图标（SVG 格式）放置于此目录中：

- PHP: `php.svg`
- Node.js: `nodejs.svg`
- MySQL: `mysql.svg`
- Redis: `redis.svg`
- OpenJDK: `java.svg`
- .NET SDK: `dotnet.svg`
- Deno: `deno.svg`
- Bun: `bun.svg`
- Nginx: `nginx.svg`
- Caddy: `caddy.svg`
- SQLite: `sqlite.svg`
- Gradle: `gradle.svg`
- Maven: `maven.svg`

当对应图标文件不存在时，`<h-logo :kind="kind" />` 自动显示品牌缩写徽标。
