# 同步

产品目标:站点根目录上传到远程服务器,SFTP 或 FTP。

不做:下载、双向同步、增量算法、Git 推送、CI/CD。

## 一、配置

`system_sites` 表新增 `sync TEXT` 字段,JSON:

```json
{
  "enabled": true,
  "protocol": "sftp",
  "host": "192.168.1.100",
  "port": 22,
  "username": "root",
  "password": "encrypted",
  "remote": "/www/wwwroot/blog",
  "auto": false,
  "ignore": [".git/**", "node_modules/**"]
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `enabled` | bool | 是 | 启用同步 |
| `protocol` | string | 是 | `sftp` 或 `ftp` |
| `host` | string | 是 | IP 或域名 |
| `port` | int | 是 | SFTP 默认 22,FTP 默认 21 |
| `username` | string | 是 | 用户名 |
| `password` | string | 是 | 加密存储 |
| `remote` | string | 是 | 远程绝对路径,必须 `/` 开头 |
| `auto` | bool | 否 | 保存时自动上传,默认 `false` |
| `ignore` | string[] | 否 | glob 数组,合并到默认规则 |

- 只在站点详情"同步"页签编辑,不在创建时填。
- 密码 AES-256-GCM 加密,密钥 `%LOCALAPPDATA%\DevEnv\sync.key`,32 字节随机生成。
- `remote` 拒绝 `..` 和非绝对路径。

## 二、忽略规则

默认:

```
.git/**
.gitignore
.env
.env.*
.vscode/**
.idea/**
node_modules/**
vendor/**
runtime/**
storage/logs/**
*.log
.DS_Store
Thumbs.db
```

- 用户 `ignore` **合并**到默认,不是替换。
- glob:`*` 单层,`**` 任意深度。

## 三、手动同步

站点详情"同步"页签【立即同步】或列表操作菜单【同步】:

1. 检查 `enabled`,未启用引导到配置。
2. 测试连接,失败 toast 终止。
3. 遍历 `root`,按 `ignore` 过滤。
4. 上传全部文件,保持目录结构。
5. 显示进度:当前文件、已传 / 总数、已传 / 总大小。
6. 完成 toast "已同步 N 个文件",失败列详情。

## 四、自动同步

`auto=true` 时监听 `root` 文件变化(创建、修改、删除):

- 保存后延迟 500ms,500ms 内合并。
- 检查 `ignore`,匹配跳过。
- 后台上传,失败 toast 不阻塞。
- 删除文件同步删除服务器对应文件。
- 只在 DevEnv 运行时生效,不常驻。

## 五、SyncAPI

| 方法 | 入参 | 返回 |
|------|------|------|
| `SaveConfig(siteID, config)` | `{enabled, protocol, host, port, username, password, remote, auto, ignore[]}` | `Result` |
| `GetConfig(siteID)` | | `ConfigDTO`,`password` 返回空 |
| `Test(siteID)` | | `Result` |
| `Start(siteID)` | | `{task}`,立即返回,事件推进度 |
| `Stop(task)` | | `Result` |

`ConfigDTO`:

```json
{
  "enabled": true,
  "protocol": "sftp",
  "host": "192.168.1.100",
  "port": 22,
  "username": "root",
  "remote": "/www/wwwroot/blog",
  "auto": false,
  "ignore": ["node_modules/**"],
  "last": "2026-10-15T10:30:00Z",
  "files": 152,
  "bytes": 4325890
}
```

- `last` `files` `bytes`:最后一次同步信息。

## 七、后端

分层:

```
internal/
├── domain/sync/      配置模型,密码加解密
├── ports/sync.go     Syncer 接口
├── app/sync.go       SyncService,编排流程
├── infra/sync/
│   ├── sftp.go      SFTP 客户端
│   ├── ftp.go       FTP 客户端
│   └── watcher.go   文件监听器
└── transport/wails/sync.go  SyncAPI 绑定
```

依赖:

- SFTP:`github.com/pkg/sftp` + `golang.org/x/crypto/ssh`
- FTP:`github.com/jlaffaye/ftp`
- 文件监听:`github.com/fsnotify/fsnotify`
- 加密:标准库 `crypto/aes` `crypto/cipher`

`Syncer` 接口:

```go
type Syncer interface {
    Connect(config Config) error
    Upload(local, remote string) error
    Remove(remote string) error
    Close() error
}
```

`SyncService.Start`:

1. 读 `sync`,检查 `enabled`。
2. 解密 `password`。
3. 创建 `Syncer`(SFTP 或 FTP),调 `Connect`,失败返回 `SYNC_CONNECT_FAILED`。
4. 遍历 `root`,跳过 `ignore`。
5. 每文件调 `Upload`,失败记录但继续。
6. 每个文件发 `sync:progress`。
7. 完成发 `sync:completed`,调 `Close`。

`Watcher`:

- `auto=true` 时启动。
- 监听 `fsnotify.Create` `fsnotify.Write` `fsnotify.Remove`。
- 防抖 500ms。
- 匹配 `ignore`,跳过。
- 后台上传,失败发 `sync:error`。

密码加密:

- 首次生成 32 字节随机密钥,存 `%LOCALAPPDATA%\DevEnv\sync.key`。
- AES-256-GCM 加密,输出 base64。
- `SaveConfig` 收明文,加密存库;`GetConfig` 不返回密码;`Start` 解密使用。

错误码(`shared/errors`):

- `SYNC_NOT_CONFIGURED`
- `SYNC_CONNECT_FAILED`
- `SYNC_AUTH_FAILED`
- `SYNC_UPLOAD_FAILED`
- `SYNC_REMOTE_PATH_INVALID`

## 九、安全

1. 密码加密,密钥文件当前用户只读(Windows `icacls`)。
2. 不在日志、事件、错误里输出明文密码。
3. `remote` 做穿越检查,拒绝 `..` 和非绝对路径。
4. 连接超时 30 秒,单文件上传超时 5 分钟。
5. 密钥丢失,已保存密码失效,提示重新输入。

## 十、测试
