# 数据库表结构与迁移规范

**项目：** DevEnv  
**版本：** V1.0  
**适用数据库：** SQLite  
**适用后端：** Go + Wails  
**文档路径：** `docs/database-design.md`

## 1. 设计目标

应用内部数据库仅用于保存 DevEnv 自身的管理数据，不承担用户 MySQL、PostgreSQL 等业务数据库的实际存储工作。

必须满足以下要求：

1. 支持多个 PHP、Nginx、MySQL、PostgreSQL 等运行环境版本。
2. 支持一个项目绑定指定 PHP 版本。
3. 支持多个项目及虚拟主机。
4. 支持长期任务、下载任务和安装任务的状态追踪。
5. 支持应用升级时进行数据库迁移。
6. 支持异常退出后的数据恢复和诊断。
7. 不因卸载运行环境而误删项目文件或数据库数据。
8. 数据库所有数据表统一采用 `system_` 前缀，实体主键统一采用数字自增 ID。

## 2. 数据库文件与初始化

建议默认数据库位置：

```text
%LOCALAPPDATA%/DevEnv/data/devenv.db
```

用户可以在设置中更改位置，但变更前必须关闭数据库连接，并确认新位置可用。

相关目录：

```text
data/
├── devenv.db
├── backups/
└── migrations/
```

`devenv.db` 是应用管理数据库，不是用户项目使用的 MySQL 或 PostgreSQL 数据目录。

### 2.1 初始化流程

1. 获取用户数据目录。
2. 检查数据库文件是否存在。
3. 不存在时创建数据库。
4. 设置连接参数和必要的 SQLite 约束。
5. 检查数据库版本。
6. 备份并执行待应用的迁移。
7. 验证迁移结果。
8. 初始化默认设置。
9. 完成应用启动。

数据库初始化失败时，应用必须明确报告原因，不得静默删除原数据库并重新创建。

### 2.2 SQLite 连接要求

- 启用外键约束，并确认所选 SQLite 驱动的连接池中每个连接都正确启用。
- 为数据库设置合理的忙等待时间 (`PRAGMA busy_timeout = 5000;`)。
- 根据驱动能力配置事务与并发访问策略。
- 启用 WAL 模式 (`PRAGMA journal_mode = WAL;`)。
- 所有 SQL 查询必须使用参数化查询。
- 不允许多个模块各自创建互不知情的数据库连接池。

## 3. 主键与标识符规范

### 3.1 设计要求

业务实体的 ID 统一使用 SQLite 原生数字自增 ID（`INTEGER PRIMARY KEY AUTOINCREMENT`），在 Go 后端中映射为 `int64`，在前端 TypeScript 中映射为 `number`。

- 主键统一命名为 `id`，类型为 `INTEGER PRIMARY KEY AUTOINCREMENT`。
- 外键统一使用对应的整数类型 `INTEGER`，例如 `php_version_id`、`project_id`、`runtime_version_id`。
- ID 不允许为空（插入时由数据库自增生成）。
- 前端不负责生成业务主键，新建数据返回最新自增 ID。

## 4. 命名规范

### 4.1 表名

**统一规范：所有数据表必须统一加上 `system_` 前缀**，并使用小写 `snake_case` 复数形式：

```text
system_projects
system_runtime_versions
system_service_instances
system_virtual_hosts
system_tasks
system_app_settings
system_schema_migrations
```

### 4.2 字段名

统一使用小写 `snake_case`。

例如：

```text
created_at
updated_at
runtime_version_id
project_id
install_path
```

### 4.3 通用字段

业务表按实际需要使用以下字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER | 自增主键 |
| `created_at` | TEXT | 创建时间 (UTC RFC 3339 字符串) |
| `updated_at` | TEXT | 最后更新时间 (UTC RFC 3339 字符串) |

时间统一保存为 UTC 的 RFC 3339 格式字符串（例如 `2026-10-14T10:30:00Z`），前端展示时再转换为用户本地时间。

## 5. 核心表结构

### 5.1 system_projects：项目表

用途：保存用户在 DevEnv 中登记的项目。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | INTEGER | PK AUTOINCREMENT | 项目 ID |
| `name` | TEXT | NOT NULL | 项目显示名称 |
| `path` | TEXT | NOT NULL | 项目绝对路径 |
| `path_key` | TEXT | NOT NULL UNIQUE | 规范化后的路径键 |
| `php_version_id` | INTEGER | FK，可空 | 绑定的 PHP 版本 ID |
| `status` | TEXT | NOT NULL | 项目登记状态 (ready, missing, invalid) |
| `created_at` | TEXT | NOT NULL | 创建时间 |
| `updated_at` | TEXT | NOT NULL | 更新时间 |

外键与索引：
- `FOREIGN KEY (php_version_id) REFERENCES system_runtime_versions(id) ON DELETE SET NULL`
- `CREATE INDEX idx_system_projects_php_version_id ON system_projects(php_version_id);`

### 5.2 system_runtime_versions：运行环境版本表

用途：登记已经安装或准备安装的运行环境版本。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | INTEGER | PK AUTOINCREMENT | 版本记录 ID |
| `runtime_type` | TEXT | NOT NULL | 运行环境类型 (php, nginx, mysql, postgresql, redis, apache) |
| `version` | TEXT | NOT NULL | 版本号 (如 8.2.9) |
| `architecture` | TEXT | NOT NULL | CPU 架构 (x64, arm64) |
| `install_path` | TEXT | NOT NULL | 安装目录 |
| `status` | TEXT | NOT NULL | 安装状态 (available, installing, installed, failed, removing) |
| `metadata_json` | TEXT | NOT NULL | 扩展元数据 (JSON) |
| `created_at` | TEXT | NOT NULL | 创建时间 |
| `updated_at` | TEXT | NOT NULL | 更新时间 |

唯一约束与索引：
- `UNIQUE (runtime_type, version, architecture, install_path)`
- `CREATE INDEX idx_system_runtime_versions_type_status ON system_runtime_versions(runtime_type, status);`

### 5.3 system_service_instances：服务实例表

用途：保存可启动、停止、监控的外部服务实例。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | INTEGER | PK AUTOINCREMENT | 服务实例 ID |
| `name` | TEXT | NOT NULL | 显示名称 |
| `runtime_version_id` | INTEGER | FK, NOT NULL | 运行环境版本 ID |
| `service_type` | TEXT | NOT NULL | 服务类型 (php, nginx, mysql, etc.) |
| `port` | INTEGER | 可空 | 监听端口 |
| `config_path` | TEXT | 可空 | 配置文件路径 |
| `data_path` | TEXT | 可空 | 数据目录 |
| `auto_start` | INTEGER | NOT NULL DEFAULT 0 | 是否自动启动 (0/1) |
| `enabled` | INTEGER | NOT NULL DEFAULT 1 | 是否启用 (0/1) |
| `created_at` | TEXT | NOT NULL | 创建时间 |
| `updated_at` | TEXT | NOT NULL | 更新时间 |

外键与索引：
- `FOREIGN KEY (runtime_version_id) REFERENCES system_runtime_versions(id) ON DELETE RESTRICT`
- `CREATE INDEX idx_system_service_instances_type ON system_service_instances(service_type);`
- `CREATE INDEX idx_system_service_instances_runtime ON system_service_instances(runtime_version_id);`

### 5.4 system_virtual_hosts：虚拟主机表

用途：保存本地域名与项目的映射。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | INTEGER | PK AUTOINCREMENT | 虚拟主机 ID |
| `project_id` | INTEGER | FK, NOT NULL | 关联项目 ID |
| `domain` | TEXT | NOT NULL UNIQUE | 本地域名 (如 demo.local) |
| `document_root` | TEXT | NOT NULL | 网站根目录 |
| `web_server_type` | TEXT | NOT NULL DEFAULT 'nginx' | Web 服务器类型 |
| `port` | INTEGER | NOT NULL DEFAULT 80 | 监听端口 |
| `enabled` | INTEGER | NOT NULL DEFAULT 1 | 是否启用 (0/1) |
| `config_path` | TEXT | 可空 | 配置文件路径 |
| `created_at` | TEXT | NOT NULL | 创建时间 |
| `updated_at` | TEXT | NOT NULL | 更新时间 |

外键与索引：
- `FOREIGN KEY (project_id) REFERENCES system_projects(id) ON DELETE CASCADE`
- `CREATE INDEX idx_system_virtual_hosts_project ON system_virtual_hosts(project_id);`
- `CREATE INDEX idx_system_virtual_hosts_domain ON system_virtual_hosts(domain);`

### 5.5 system_tasks：任务表

用途：保存下载、安装、备份、恢复等长时间任务。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | INTEGER | PK AUTOINCREMENT | 任务 ID |
| `task_type` | TEXT | NOT NULL | 任务类型 |
| `status` | TEXT | NOT NULL | 当前状态 (queued, running, cancelling, succeeded, failed, cancelled) |
| `progress` | INTEGER | NOT NULL DEFAULT 0 | 进度百分比 (0-100) |
| `message` | TEXT | 可空 | 当前阶段描述 |
| `error_code` | TEXT | 可空 | 错误代码 |
| `error_message` | TEXT | 可空 | 安全的错误摘要 |
| `payload_json` | TEXT | NOT NULL DEFAULT '{}' | 任务参数快照 |
| `created_at` | TEXT | NOT NULL | 创建时间 |
| `updated_at` | TEXT | NOT NULL | 更新时间 |
| `finished_at` | TEXT | 可空 | 结束时间 |

索引：
- `CREATE INDEX idx_system_tasks_status ON system_tasks(status);`
- `CREATE INDEX idx_system_tasks_type ON system_tasks(task_type);`

### 5.6 system_app_settings：应用设置表

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `key` | TEXT | PK | 设置键 |
| `value_json` | TEXT | NOT NULL | JSON 格式设置值 |
| `updated_at` | TEXT | NOT NULL | 更新时间 |

### 5.7 system_schema_migrations：迁移记录表

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `version` | TEXT | PK | 迁移版本号 (如 000001) |
| `name` | TEXT | NOT NULL | 迁移名称 |
| `applied_at` | TEXT | NOT NULL | 应用时间 |

## 6. 外键关系与删除规则

```text
system_runtime_versions
      │
      ├──────── system_projects.php_version_id (ON DELETE SET NULL)
      │
      └──────── system_service_instances.runtime_version_id (ON DELETE RESTRICT)

system_projects
      │
      └──────── system_virtual_hosts.project_id (ON DELETE CASCADE)

system_tasks
      └──────── 独立任务记录
```

- 运行环境被项目引用时，删除环境置空项目关联或禁止删除。
- 项目被虚拟主机引用时，删除项目级联删除虚拟主机映射。
- 严禁对物理项目目录和数据库数据目录使用级联物理删除。
