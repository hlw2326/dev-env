# DevEnv 网站管理模块设计方案

**版本：** V1.0  
**日期：** 2026-10-14  
**目标：** 整合项目管理与虚拟主机，构建类似宝塔面板的统一网站管理平台

---

## 一、核心设计理念

### 1.1 从"项目管理 + 虚拟主机"到"网站管理"

**现状问题：**
- 当前"项目管理"和"虚拟主机"分离，用户需要分别配置
- 添加一个网站需要先创建项目，再单独配置虚拟主机
- 仅支持 PHP 项目，无法管理 Node.js、Go、Python 等项目类型
- 缺少 Git 集成，无法快速部署和更新代码

**新方案：**
```
删除：【项目管理】+ 【虚拟主机】两个独立页面
新增：【网站管理】统一入口（类似宝塔面板"网站"功能）
支持：PHP / Node.js / Go / Python 多种项目类型
集成：Git 克隆、拉取、推送功能
```

### 1.2 设计原则

1. **一站式管理**：添加网站时自动配置项目目录、运行环境、域名、虚拟主机
2. **多语言支持**：支持 PHP、Node.js、Go、Python 等主流开发语言
3. **Git 集成**：支持从远程仓库克隆、拉取更新、查看状态、推送代码
4. **灵活部署**：支持静态站点、PHP-FPM、Node.js 服务、Go 二进制、Python WSGI/ASGI
5. **域名绑定**：自动生成 Nginx 配置，支持多域名绑定和反向代理
6. **SSL 支持**：支持 HTTPS 证书管理（Let's Encrypt、自签名、自定义证书）
7. **日志与监控**：统一查看访问日志、错误日志、运行状态

### 1.3 功能对比

| 功能点 | 旧设计（项目管理 + 虚拟主机） | 新设计（网站管理） |
|---|---|---|
| 添加网站 | 需分别创建项目和虚拟主机 | 一步完成，自动配置 |
| 支持语言 | 仅 PHP | PHP / Node.js / Go / Python |
| Git 集成 | 无 | 克隆、拉取、推送、状态查看 |
| 域名配置 | 需手动编辑虚拟主机 | 可视化添加/删除域名 |
| SSL 证书 | 无 | 自动申请 / 上传证书 |
| 运行监控 | 分散在服务实例 | 统一查看运行状态和日志 |

## 三、网站类型定义

### 3.1 支持的网站类型

| 类型 | 说明 | 运行方式 | 示例 |
|---|---|---|---|
| **静态网站** | HTML/CSS/JS | Nginx 直接代理 | 个人博客、文档站 |
| **PHP 网站** | PHP 应用 | Nginx + PHP-FPM | WordPress、Laravel |
| **Node.js 应用** | Node.js 服务 | Nginx 反向代理 | Express、Nest.js |
| **Go 应用** | Go 二进制服务 | Nginx 反向代理 | Gin、Fiber |
| **Python 应用** | Python Web 服务 | Nginx + WSGI/ASGI | Django、FastAPI |

### 3.2 网站类型配置差异

#### 3.2.1 静态网站配置

```nginx
server {
    listen 80;
    server_name static.local;
    root D:/www/static-site/dist;
    index index.html;
    
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

#### 3.2.2 PHP 网站配置

```nginx
server {
    listen 80;
    server_name php.local;
    root D:/www/php-site/public;
    index index.php index.html;
    
    location ~ \.php$ {
        fastcgi_pass 127.0.0.1:9000;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
}
```

#### 3.2.3 Node.js 应用配置

```nginx
server {
    listen 80;
    server_name nodejs.local;
    
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

#### 3.2.4 Go 应用配置

```nginx
server {
    listen 80;
    server_name go.local;
    
    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

#### 3.2.5 Python 应用配置

```nginx
server {
    listen 80;
    server_name python.local;
    
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

## 四、数据模型设计

### 4.1 网站表结构（整合项目与虚拟主机）

```sql
-- Migration: 000008_create_sites
CREATE TABLE IF NOT EXISTS system_sites (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,                          -- 网站名称
    site_type TEXT NOT NULL,                     -- static | php | nodejs | go | python
    domain_list TEXT NOT NULL,                   -- JSON 数组 ["example.com", "www.example.com"]
    root_path TEXT NOT NULL,                     -- 网站根目录
    
    -- 运行时环境
    runtime_version_id INTEGER,                  -- 关联运行环境（PHP/Node.js/Go/Python 版本）
    service_instance_id INTEGER,                 -- 关联服务实例（PHP-FPM/Node.js 进程）
    
    -- Git 配置
    git_enabled INTEGER NOT NULL DEFAULT 0,      -- 是否启用 Git
    git_remote_url TEXT,                         -- 远程仓库地址
    git_branch TEXT DEFAULT 'main',              -- 当前分支
    git_last_commit TEXT,                        -- 最后提交 SHA
    git_last_pull_at TEXT,                       -- 最后拉取时间
    
    -- Nginx 配置
    nginx_config_path TEXT,                      -- 生成的 Nginx 配置文件路径
    listen_port INTEGER DEFAULT 80,              -- 监听端口
    
    -- SSL 配置
    ssl_enabled INTEGER NOT NULL DEFAULT 0,      -- 是否启用 HTTPS
    ssl_cert_path TEXT,                          -- SSL 证书路径
    ssl_key_path TEXT,                           -- SSL 私钥路径
    ssl_provider TEXT,                           -- letsencrypt | self-signed | custom
    
    -- 反向代理配置（Node.js/Go/Python）
    proxy_enabled INTEGER NOT NULL DEFAULT 0,    -- 是否启用反向代理
    proxy_target_port INTEGER,                   -- 代理目标端口
    
    -- 元数据
    metadata_json TEXT NOT NULL DEFAULT '{}',    -- 扩展信息（JSON）
    status TEXT NOT NULL DEFAULT 'stopped',      -- stopped | running | error
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    
    FOREIGN KEY (runtime_version_id) REFERENCES system_runtime_versions(id) ON DELETE SET NULL,
    FOREIGN KEY (service_instance_id) REFERENCES system_service_instances(id) ON DELETE SET NULL
);

CREATE INDEX IF NOT EXISTS idx_system_sites_type ON system_sites(site_type);
CREATE INDEX IF NOT EXISTS idx_system_sites_status ON system_sites(status);
```

**`metadata_json` 字段扩展用途：**
```json
{
  "entryFile": "index.php",               // PHP 入口文件
  "nodeCommand": "npm start",             // Node.js 启动命令
  "goExecutable": "./main.exe",           // Go 可执行文件
  "pythonWsgi": "app:application",        // Python WSGI 入口
  "autoStart": true,                      // 是否随 DevEnv 自动启动
  "envVars": {                            // 环境变量
    "NODE_ENV": "production",
    "DATABASE_URL": "..."
  },
  "nginxCustomConfig": "",                // 自定义 Nginx 配置片段
  "accessLog": "D:/DevEnv/logs/nginx/site-access.log",
  "errorLog": "D:/DevEnv/logs/nginx/site-error.log"
}
```

### 4.2 Git 仓库状态表

```sql
-- Migration: 000009_create_git_status
CREATE TABLE IF NOT EXISTS system_git_status (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    site_id INTEGER NOT NULL,
    current_branch TEXT NOT NULL,
    current_commit TEXT NOT NULL,
    is_clean INTEGER NOT NULL DEFAULT 1,         -- 工作区是否干净
    ahead_count INTEGER NOT NULL DEFAULT 0,      -- 领先远程多少提交
    behind_count INTEGER NOT NULL DEFAULT 0,     -- 落后远程多少提交
    modified_files TEXT NOT NULL DEFAULT '[]',   -- JSON 数组，已修改文件列表
    untracked_files TEXT NOT NULL DEFAULT '[]',  -- JSON 数组，未跟踪文件列表
    last_check_at TEXT NOT NULL,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    FOREIGN KEY (site_id) REFERENCES system_sites(id) ON DELETE CASCADE
);

CREATE INDEX IF NOT EXISTS idx_system_git_status_site ON system_git_status(site_id);
```

```go
// CreateSite 创建网站（整合项目创建 + 虚拟主机配置）
func (s *SiteService) CreateSite(ctx context.Context, input site.CreateInput) (*site.Site, error) {
    // 1. 验证输入参数
    if err := input.Validate(); err != nil {
        return nil, err
    }
    
    // 2. 检查域名是否已被占用
    existing, _ := s.siteRepo.GetByDomain(ctx, input.Domains[0])
    if existing != nil {
        return nil, errors.New("域名已被其他网站占用")
    }
    
    // 3. 如果启用 Git，克隆仓库
    if input.GitEnabled && input.GitRemoteURL != "" {
        if err := s.gitManager.Clone(ctx, input.GitRemoteURL, input.RootPath, input.GitBranch); err != nil {
            return nil, err
        }
    }
    
    // 4. 验证运行时版本
    runtime, err := s.runtimeRepo.GetByID(ctx, input.RuntimeVersionID)
    if err != nil || runtime == nil {
        return nil, errors.New("运行环境不存在")
    }
    
    // 5. 创建或关联服务实例
    var serviceInstanceID int64
    if input.AutoCreateService {
        instance, err := s.createServiceInstance(ctx, input.SiteType, input.RuntimeVersionID)
        if err != nil {
            return nil, err
        }
        serviceInstanceID = instance.ID
    } else {
        serviceInstanceID = input.ServiceInstanceID
    }
    
    // 6. 生成 Nginx 配置文件
    nginxConfig := s.generateNginxConfig(input)
    configPath, err := s.nginxManager.WriteConfig(ctx, nginxConfig)
    if err != nil {
        return nil, err
    }
    
    // 7. 创建网站记录
    newSite := &site.Site{
        Name:              input.Name,
        SiteType:          input.SiteType,
        DomainList:        input.Domains,
        RootPath:          input.RootPath,
        RuntimeVersionID:  input.RuntimeVersionID,
        ServiceInstanceID: serviceInstanceID,
        GitEnabled:        input.GitEnabled,
        GitRemoteURL:      input.GitRemoteURL,
        GitBranch:         input.GitBranch,
        NginxConfigPath:   configPath,
        SSLEnabled:        input.SSLEnabled,
        ProxyEnabled:      input.SiteType != site.TypeStatic && input.SiteType != site.TypePHP,
        ProxyTargetPort:   input.ProxyTargetPort,
        Status:            site.StatusStopped,
    }
    
    if err := s.siteRepo.Create(ctx, newSite); err != nil {
        return nil, err
    }
    
    // 8. 如果启用自动启动，立即启动网站
    if input.AutoStart {
        if err := s.StartSite(ctx, newSite.ID); err != nil {
            // 记录错误但不回滚创建
            s.publisher.Emit("site:start-failed", newSite.ID)
        }
    }
    
    // 9. 发布网站创建事件
    s.publisher.Emit("site:created", newSite.ID)
    
    return newSite, nil
}

// StartSite 启动网站
func (s *SiteService) StartSite(ctx context.Context, siteID int64) error {
    // 1. 获取网站信息
    site, err := s.siteRepo.GetByID(ctx, siteID)
    if err != nil || site == nil {
        return errors.New("网站不存在")
    }
    
    // 2. 检查当前状态
    if site.Status == site.StatusRunning {
        return errors.New("网站已在运行")
    }
    
    // 3. 启动关联的服务实例（PHP-FPM / Node.js / Go / Python）
    if site.ServiceInstanceID > 0 {
        if err := s.startServiceInstance(ctx, site.ServiceInstanceID); err != nil {
            return err
        }
    }
    
    // 4. 测试 Nginx 配置
    if err := s.nginxManager.TestConfig(ctx); err != nil {
        return errors.New("Nginx 配置测试失败: " + err.Error())
    }
    
    // 5. 重载 Nginx 配置
    if err := s.nginxManager.Reload(ctx); err != nil {
        return errors.New("Nginx 重载失败: " + err.Error())
    }
    
    // 6. 更新网站状态
    site.Status = site.StatusRunning
    if err := s.siteRepo.Update(ctx, site); err != nil {
        return err
    }
    
    // 7. 发布网站启动事件
    s.publisher.Emit("site:started", siteID)
    
    return nil
}
```

### 9.1 Nginx 配置动态生成

根据网站类型和配置，动态生成 Nginx 配置文件：

```go
func (s *SiteService) generateNginxConfig(site *site.Site) string {
    var config string
    
    // 基础配置
    config += fmt.Sprintf("server {\n")
    config += fmt.Sprintf("    listen %d;\n", site.ListenPort)
    if site.SSLEnabled {
        config += fmt.Sprintf("    listen 443 ssl http2;\n")
        config += fmt.Sprintf("    ssl_certificate %s;\n", site.SSLCertPath)
        config += fmt.Sprintf("    ssl_certificate_key %s;\n", site.SSLKeyPath)
    }
    
    // 域名配置
    config += fmt.Sprintf("    server_name %s;\n", strings.Join(site.DomainList, " "))
    
    // 根据网站类型生成不同配置
    switch site.SiteType {
    case site.TypeStatic:
        config += fmt.Sprintf("    root %s;\n", site.RootPath)
        config += "    index index.html;\n"
        config += "    location / {\n"
        config += "        try_files $uri $uri/ /index.html;\n"
        config += "    }\n"
        
    case site.TypePHP:
        config += fmt.Sprintf("    root %s;\n", site.RootPath)
        config += "    index index.php index.html;\n"
        config += "    location ~ \\.php$ {\n"
        config += fmt.Sprintf("        fastcgi_pass 127.0.0.1:%d;\n", site.ProxyTargetPort)
        config += "        fastcgi_index index.php;\n"
        config += "        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;\n"
        config += "        include fastcgi_params;\n"
        config += "    }\n"
        
    case site.TypeNodeJS, site.TypeGo, site.TypePython:
        config += "    location / {\n"
        config += fmt.Sprintf("        proxy_pass http://127.0.0.1:%d;\n", site.ProxyTargetPort)
        config += "        proxy_http_version 1.1;\n"
        config += "        proxy_set_header Upgrade $http_upgrade;\n"
        config += "        proxy_set_header Connection 'upgrade';\n"
        config += "        proxy_set_header Host $host;\n"
        config += "        proxy_set_header X-Real-IP $remote_addr;\n"
        config += "        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;\n"
        config += "        proxy_cache_bypass $http_upgrade;\n"
        config += "    }\n"
    }
    
    // 日志配置
    config += fmt.Sprintf("    access_log %s;\n", site.AccessLog)
    config += fmt.Sprintf("    error_log %s;\n", site.ErrorLog)
    
    config += "}\n"
    
    return config
}
```

### 9.2 Git 集成实现

使用 `go-git` 库或直接调用 Git 命令行：

```go
package infra

import (
    "os/exec"
    "strings"
)

type GitManager struct{}

func NewGitManager() *GitManager {
    return &GitManager{}
}

func (g *GitManager) Clone(ctx context.Context, remoteURL, localPath, branch string) error {
    cmd := exec.CommandContext(ctx, "git", "clone", "-b", branch, remoteURL, localPath)
    if err := cmd.Run(); err != nil {
        return err
    }
    return nil
}

func (g *GitManager) Pull(ctx context.Context, repoPath string) error {
    cmd := exec.CommandContext(ctx, "git", "-C", repoPath, "pull")
    if err := cmd.Run(); err != nil {
        return err
    }
    return nil
}

func (g *GitManager) GetStatus(ctx context.Context, repoPath string) (*GitStatus, error) {
    // 获取当前分支
    branchCmd := exec.CommandContext(ctx, "git", "-C", repoPath, "branch", "--show-current")
    branchOut, _ := branchCmd.Output()
    branch := strings.TrimSpace(string(branchOut))
    
    // 获取最后提交
    commitCmd := exec.CommandContext(ctx, "git", "-C", repoPath, "rev-parse", "HEAD")
    commitOut, _ := commitCmd.Output()
    commit := strings.TrimSpace(string(commitOut))
    
    // 获取工作区状态
    statusCmd := exec.CommandContext(ctx, "git", "-C", repoPath, "status", "--porcelain")
    statusOut, _ := statusCmd.Output()
    
    modifiedFiles := []string{}
    untrackedFiles := []string{}
    for _, line := range strings.Split(string(statusOut), "\n") {
        if len(line) < 3 {
            continue
        }
        status := line[0:2]
        file := line[3:]
        
        if status == "??" {
            untrackedFiles = append(untrackedFiles, file)
        } else if strings.Contains(status, "M") || strings.Contains(status, "A") || strings.Contains(status, "D") {
            modifiedFiles = append(modifiedFiles, file)
        }
    }
    
    return &GitStatus{
        CurrentBranch:   branch,
        CurrentCommit:   commit,
        IsClean:         len(modifiedFiles) == 0 && len(untrackedFiles) == 0,
        ModifiedFiles:   modifiedFiles,
        UntrackedFiles:  untrackedFiles,
    }, nil
}

func (g *GitManager) Commit(ctx context.Context, repoPath, message string, files []string) error {
    // git add
    for _, file := range files {
        addCmd := exec.CommandContext(ctx, "git", "-C", repoPath, "add", file)
        if err := addCmd.Run(); err != nil {
            return err
        }
    }
    
    // git commit
    commitCmd := exec.CommandContext(ctx, "git", "-C", repoPath, "commit", "-m", message)
    if err := commitCmd.Run(); err != nil {
        return err
    }
    
    return nil
}

func (g *GitManager) Push(ctx context.Context, repoPath string) error {
    cmd := exec.CommandContext(ctx, "git", "-C", repoPath, "push")
    if err := cmd.Run(); err != nil {
        return err
    }
    return nil
}
```

## 十、总结

通过将"项目管理"和"虚拟主机"整合为统一的"网站管理"模块，DevEnv 实现了：

✅ **一站式管理**：添加网站时自动配置项目、运行环境、域名、虚拟主机  
✅ **多语言支持**：支持 PHP、Node.js、Go、Python 等主流开发语言

✅ **统一体验**：类似宝塔面板的直观操作流程

该方案复用现有的运行环境和服务实例管理，统一网站配置和域名管理，降低用户学习成本，提升开发效率。
