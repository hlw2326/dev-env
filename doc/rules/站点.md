# 站点

## 创建

- 创建必填：类型、名称、域名；类型为 `static`、`php`、`node`。
- 根目录和运行目录在创建表单中明确填写；目录不存在时创建。
- 默认根目录来自设置，软件版本由后端选择该类型的 `main` 版本。
- 空目录写入对应示例入口：静态 `index.html`、PHP `index.php`、Node `package.json` 与 `server.js`。
- 缺少 PHP 或 Node 环境时允许创建，启动时明确返回缺少环境，不伪造运行状态。
- 删除站点只删除数据库记录，不删除项目目录。

## 目录和域名

- `root` 是项目根目录，`run` 是根目录内的相对运行目录，空值表示根目录本身。
- 运行目录禁止绝对路径和 `..` 穿越。
- 自动识别入口命中即停止，未命中返回空，不猜框架。
- 域名在数据库层唯一；自定义域名只有启用 hosts 后才写入系统 hosts。

## 网关和生命周期

- 网关监听 `127.0.0.1`，端口被占用时失败并提示用户，不自动换端口。
- PHP 使用 php-cgi，Node 使用进程树管理并通过 `PORT` 环境变量传端口。
- 路由表整体替换，运行状态由网关和进程管理器实时计算，不增加站点 `status` 列。
- 每个站点有访问日志；日志读取真实文件，不存在返回空切片。
- Nginx 配置检查前创建 Nginx 前缀所需的 `logs`、`vhosts` 和临时目录。

## Nginx 高级配置

- 站点详情提供“Nginx 高级配置”页签，用于编辑当前站点 `server` 区块内的附加指令。
- 基础 `server`、域名、根目录、运行环境和反向代理配置仍由系统生成，不能通过片段覆盖。
- 保存前后必须使用 Nginx 配置检查；片段只允许影响当前站点，不得写入 `http`、`events` 或额外的 `server` 区块。
- 站点配置文件由系统统一渲染，用户不直接编辑生成文件；高级配置持久化在站点记录中。
