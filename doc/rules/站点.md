# 站点

产品目标:建站只要选类型、填名称、填域名。PHP 版本、端口、目录、启动命令全部自动处理。

## 一、产品原则

1. 用户只做一件事:选类型,填名称,填域名,点创建。其余有默认值,高级项折叠。
2. 装完软件就能用,没有"服务实例"概念。
3. 不造假:启动失败报真实错误;没装环境明确提示并给【一键安装】。
4. 不碰用户目录:删除站点只删记录,永远不删项目目录,也没有"同时删除目录"选项。
5. 页面只有:环境概览、网站、软件商店、设置。

不做(需要时再单独设计,不留半成品):Git 操作、SSL / HTTPS、Nginx 配置编辑、Go 与 Python 站点类型、服务实例页、任务页。

## 二、创建

必填三项:类型(`static` `php` `node`)、名称、域名。根目录和运行目录直接放在创建对话框,不折叠。"更多设置"默认折叠,只放运行环境版本和 Node 启动命令。

| 项 | 默认 |
|----|------|
| 域名 | `<名称>.localhost`,浏览器自动解析,不改 hosts,不需要管理员权限 |
| 根目录 | `<站点根>\<名称>`,站点根默认 `%USERPROFILE%\DevEnv\www`,可在设置里改 |
| 运行目录 | 自动识别 |
| 软件版本 | 创建时该类型的 `main` 版本,写入 `software`,之后不再随默认版本变化 |
| Node 端口 | 创建时从 3000 起分配并落库,通过环境变量 `PORT` 传给进程 |
| Node 启动命令 | 自动探测 |
| 目录为空 | 写示例首页:静态 `index.html`,PHP `index.php`,Node `package.json` 与 `server.js` |
| 网关端口 | 80 |

- `software` 为空只表示创建时没装环境。界面显示"缺少环境"和【一键安装】,装好后由服务把这些站点绑定到新装版本。读取时没有"为空则取默认"的分支。
- 创建不拦截缺环境的站点。
- 域名在数据库层唯一,重复返回 `ALREADY_EXISTS`。

## 三、根目录与运行目录

| 名称 | 含义 |
|------|------|
| 根目录 | 项目所在目录,`.git` `composer.json` `package.json` `.env` 都在这里 |
| 运行目录 | 入口所在目录,相对根目录。**网关的文档根就是它**,访问不到它之外的文件 |

- 选项:`/`(根目录本身)、`/public`、`/web`、`/dist`、自定义相对路径。
- 运行目录必须落在根目录内,含 `..` 或绝对路径一律拒绝。库中存不带前导 `/` 的相对路径,空表示根目录本身。
- 自动识别命中即停,**都不命中就是空,不猜**:

| 类型 | 顺序 |
|------|------|
| PHP | `public/index.php` → `web/index.php` → 根目录有 `index.php` 则为空 |
| 静态 | 根目录有 `index.html` 则为空 → `dist/index.html` → `public/index.html` |
| Node | 空,启动命令的工作目录取运行目录 |

- 只看目录特征,不识别具体框架。改运行目录立即生效,不需要重启。
- 目录不存在就建出来。

## 四、Node 启动命令探测

命中即停:

1. `package.json` 的 `scripts.start` → `npm start`
2. `package.json` 的 `main` → `node <main>`
3. 存在 `server.js` `app.js` `index.js` → `node <文件>`
4. 都没有 → 创建成功,状态显示"未配置启动命令"

命令里可写 `%PORT%`,进程启动时展开。

## 五、网关

HTTP 服务监听 `127.0.0.1:<网关端口>`,按 `Host` 匹配站点:

| 类型 | 处理 |
|------|------|
| 静态 | 提供文件;目录请求找 `index.html`;找不到 404 |
| PHP | 存在的非 `.php` 文件直接返回;存在的 `.php` 交给 php-cgi;其余回落到入口 `index.php`,保留原始 `REQUEST_URI` 与 `QUERY_STRING` |
| Node | 反向代理到 `127.0.0.1:<站点端口>`,支持 WebSocket |

- 只监听回环地址。没有登录机制,不能监听 `0.0.0.0`。
- Host 未匹配任何站点时,返回简单页面列出所有站点。
- PHP 每个请求启动一次 php-cgi,并发上限 8,单请求超时 60 秒。
- 拒绝访问 `.git` `.env` `.htaccess` 等隐藏路径;路径一律做穿越检查。
- 每个站点一个访问日志文件,每次请求追加一行。
- 网关端口被占用时启动失败,设置页显示原因,由用户改端口,不自动换端口。

## 六、启动与停止

| 类型 | "运行中"的含义 | 启动做了什么 |
|------|----------------|--------------|
| 静态 | 网关在提供该站点 | 加入路由表 |
| PHP | 同上,PHP 每次请求执行 | 同上,并检查 php-cgi 存在 |
| Node | 子进程存活且端口已监听 | 启动进程,等待端口就绪(最多 30 秒),再加入路由表 |

- 应用启动时,`autostart=1` 的站点自动启动。
- 停止 Node 站点结束整个进程树。
- 路由表整体替换(`SetRoutes`),线程安全。

## 七、域名与 hosts

- 点域名或【打开】:用系统浏览器打开 `http://<域名>[:网关端口]/`。
- 自定义域名(如 `blog.test`)需要写 hosts:设置里"自动写入 hosts"开关,默认关。
- 没有管理员权限时如实提示,并给出要手动添加的那一行,不假装成功。

## 八、前端

- 列表一行一个站点:类型图标、名称、可点击域名、状态点、目录、生效版本、操作(启停开关、打开、目录、详情、删除)。
- 缺运行环境的行内显示【一键安装 PHP】(由 DTO 的 `need` 决定)。
- 空状态一句话加【创建第一个网站】。
- 详情抽屉三页签:概览(根目录、运行目录下拉并显示完整路径、版本、启动命令、随应用启动)、域名(增删)、日志(访问 / 运行,手动刷新)。
- 删除确认只有一句:"只删除站点记录,不会删除项目目录"。

## 九、SiteAPI

| 方法 | 入参 | 返回 |
|------|------|------|
| `List()` `Get(id)` | | `SiteDTO[]` / `SiteDTO` |
| `Create(in)` | `{kind, name, host, root, run, command}`,`software` 由后端取 `main` 版本,不由前端传 | `SiteDTO` |
| `Update(in)` | `{id, hosts, root, run, software, command, autostart}`,整体提交,不做"传了才改" | `SiteDTO` |
| `FindRun(root, kind)` | 回填识别结果 | `string`,识别不到为空 |
| `Start` `Stop` `Restart` `Delete` | `id` | `Result` |
| `Logs(id, kind, limit)` | `kind` 为 `access` 或 `run` | `string[]` |

`SiteDTO`:`id name kind hosts[] root run path software version command port autostart state url need created updated`。

- `state`:`running` `stopped` `error`。
- `path`:根目录拼运行目录。`url`:拼好的访问地址。
- `need`:缺环境时为 `php` 或 `nodejs`,否则为空。
- `version`:`software` 指向的版本号,`software` 为空则为空。
