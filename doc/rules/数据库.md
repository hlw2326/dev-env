# 数据库

- SQLite 数据库固定在 `%LOCALAPPDATA%\DevEnv\data\devenv.db`。
- 表名使用 `system_` 前缀和完整单词，列名使用完整单词。
- 表结构只通过编号迁移文件修改，迁移文件一旦应用不得重写。
- 改字段必须同次修改迁移、仓库、领域模型、DTO 和前端类型。
- 当前是开发模式，不探测旧表结构、不迁移旧数据、不保留旧字段兼容分支。
- 迁移校验值漂移时返回 `DATABASE_SCHEMA_MISMATCH`；重建开发库必须显式设置 `DEVENV_DB_RESET=1`。
- 重置数据库前保留可恢复备份；软件目录和项目目录不随数据库重置删除。
- 仓库 SQL 只出现在 `internal/infra/sqlite`，业务层不拼表名和列名。
- 读操作先检查错误，再处理空结果；DTO 切片统一转换为空切片而不是 nil。
