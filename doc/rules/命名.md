# 命名

- 变量、字段、DTO 键和数据库列使用完整单词：`version`、`config`、`software`、`message`。
- 方法使用动词开头的小驼峰：`findRun`、`saveConfig`、`loadSite`。
- 类型使用一到两个完整名词：`Site`、`Software`、`Route`、`Result`。
- 常量使用 `UPPER_SNAKE_CASE`。
- 页面私有组件文件放在 `comps/`，文件名不带前缀，使用 `<comp-xxx>`。
- 全局组件文件和标签使用 `h-` 前缀，并包含 `index.ts` 与 `types.d.ts`。
- 禁止无意义的 `common`、`helper`、`base`、`util` 大杂烩命名。
- 允许使用缩写：`conf` 表示 `config`，`soft` 表示 `software`，`cmd` 表示 `command`，`msg` 表示 `message`；`err` 仅用于 Go 函数内部错误变量。
- `version` 禁止缩写成 `ver`，任何字段、变量、DTO 键和配置项都必须写完整的 `version`。
- 除上述约定外，不新增自定义缩写；无法确认含义时使用完整单词。
- 固定字段使用：项目 `root`、`run`、`host`，软件 `software`，时间 `created`、`updated`。
- 用户界面、提示语和新业务文案统一使用“项目”；项目可以是 Web 项目或 Electron 本地调试项目。
- 数据库表名使用 `system_` 前缀和单数命名：使用 `system_site`、`system_log`，禁止 `system_sites`、`system_logs`。
- 事件使用标准名称：`task:progress`、`task:completed`、`service:status-changed`、`site:status-changed`、`project:plugin-status-changed`。
