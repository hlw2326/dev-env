# 命名

目标:名字最短,但**完整的单词不缩写**。

## 一、规则

| 对象 | 规则 | 例子 |
|------|------|------|
| 变量、字段、数据库列、DTO 键 | 一个完整单词 | `id kind name root version port state progress error message software command config autostart` |
| 方法、函数 | 动词在前,`xxxXxx` 两个完整单词小驼峰 | `findRun saveConfig loadSite bindSite` |
| 类型 | 一到两个完整单词的名词 | `Site Software Route Result` |
| 文件 | 一个完整单词 | `site.go software.go config.go` |
| 页面小组件 | 文件 `comps/demo.vue`,使用处标签 `comp-demo` | 见第六节 |
| 全局组件 | 文件与标签都带 `h-` 前缀 | `h-card.vue` `<h-card>` |
| 常量 | `UPPER_SNAKE_CASE` | `MAX_RETRY` |
| 事件名 | 标准名 | `task:progress` |
| 数据库表 | `system_` 前缀加完整单词 | `system_software` |

- 能一个单词就一个单词。上下文已说明的前缀、后缀全部去掉。
- 一个词表达不了才用两个词。三个词说明结构拆得不对,先拆结构。
- 方法挂在哪个类型上,名词就省掉哪个:`SiteService.Create` 优于 `SiteService.CreateSite`。
- 类型已经说明的,字段不再重复:`sites` 不写 `siteRepo`。

## 二、禁止缩写

下面这些都有完整的短单词,必须写全:

`ver→version conf→config soft→software cmd→command pct→progress err→error msg→message desc→description cat→category rec→recommended dir→folder Res→Result Req→Request Stat→Status Prefs→Settings Ext→Extension`

允许保留的惯用缩写只有:

- `id` `pid` `url` `ok` `ctx`
- Go 函数内局部的 `err`(数据库列、DTO、事件载荷里一律写 `error`)
- 方法接收者一个字母:`s` `r`

## 三、固定词

- 默认版本叫 `main`。`default` 是 Go、SQL、JS 的保留字,不能当字段名。
- 运行目录叫 `run`,相对 `root`,空表示 `root` 本身。
- 时间列叫 `created` `updated`,值为 UTC RFC 3339。
- 站点引用软件的列叫 `software`,域名表的域名列叫 `host`。

## 四、动词统一

不用同义词。

| 动词 | 含义 |
|------|------|
| `list` `get` | 读多条 / 读一条 |
| `create` `update` `delete` | 增 / 改 / 删 |
| `find` | 探测或查找,找不到返回空 |
| `start` `stop` `restart` | 进程与站点生命周期 |
| `read` `write` | 读写文件 |
| `check` | 校验,只返回结果,不改状态 |
| `load` `save` | 前端读取 / 提交表单状态 |
| `reload` | 重新加载配置 |

## 五、Wails 绑定

- 每个模块一个绑定结构体:`SiteAPI` `SoftwareAPI` `SystemAPI`,方法不带模块名。
- 绑定到前端的 Go 方法首字母大写:`FindRun` `SaveConfig`。包内私有写成 `findRun` `saveConfig`。
- 前端只通过 `frontend/src/api/` 调用,页面不直接 import `wailsjs`。

## 六、页面小组件

页面或外壳私有的组件放 `comps/`,文件名不带前缀;在别处使用时标签统一加 `comp-` 前缀。

| 文件 | import 名 | 模板标签 |
|------|-----------|----------|
| `comps/demo.vue` | `CompDemo` | `<comp-demo />` |
| `comps/detail-logs.vue` | `CompDetailLogs` | `<comp-detail-logs />` |

- 文件名在 `comps/` 里平铺,分组用前缀:`detail.vue` `detail-logs.vue`。
- import 名固定为 `Comp` 加文件名的大驼峰,标签固定为 `comp-` 加文件名。
- 不再给组件起 `SiteRow` `MarketCard` `DashStats` 这类带页面名的别名。
- 标签前缀 `comp-` 用来和全局组件 `h-xxx`、PrimeVue 组件区分,三类来源一眼可辨。

```vue
<template>
	<!-- 站点列表项 -->
	<comp-row v-for="site in sites" :key="site.id" :site="site" />
</template>

<script setup lang="ts">
import CompRow from './comps/row.vue'
</script>
```

## 自查

```bash
# 三个词以上的 camelCase 标识符
rg '\b[a-z]+[A-Z][a-z]+[A-Z][a-z]+[A-Z]' internal frontend/src
# 常见缩写
rg -w 'ver|conf|soft|cmd|pct|msg|desc|cat|rec' internal frontend/src --glob '*.{go,ts,vue}'
# comps 下的组件 import 名必须以 Comp 开头
rg "^import (?!Comp)\w+ from '\./comps/" frontend/src --pcre2
```
