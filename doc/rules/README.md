# DevEnv 开发规则

修改代码前先阅读本目录中与改动相关的规则；所有改动都必须遵守《总则》。

| 文件 | 适用范围 |
| --- | --- |
| [总则.md](总则.md) | 所有代码、文档和数据变更 |
| [命名.md](命名.md) | Go、TypeScript、Vue、数据库字段和文件命名 |
| [后端.md](后端.md) | `internal/`、Wails 服务和进程管理 |
| [前端.md](前端.md) | `frontend/src/`、页面、组件和 API 调用 |
| [样式.md](样式.md) | CSS、SCSS、PrimeVue 覆盖和布局 |
| [数据库.md](数据库.md) | SQLite 表、迁移和仓库 |
| [站点.md](站点.md) | 网站创建、网关、域名和运行目录 |
| [软件.md](软件.md) | 软件商城、安装、版本和守护进程 |

规则改变时直接修改对应规则文件，不在代码中保留旧规则或兼容分支。
