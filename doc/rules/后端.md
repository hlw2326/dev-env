# 后端

## 错误

- 手动发布标准错误码使用 `DEPLOYMENT_FAILED`；配置和预览令牌不合法使用 `INVALID_ARGUMENT`。

- 错误统一使用 `shared/errors` 的标准码：`INVALID_ARGUMENT`、`NOT_FOUND`、`ALREADY_EXISTS`、`PATH_INVALID`、`PATH_NOT_ACCESSIBLE`、`DOWNLOAD_FAILED`、`INSTALL_FAILED`、`PORT_ALREADY_IN_USE`、`PROCESS_START_FAILED`、`RUNTIME_NOT_INSTALLED`、`DATABASE_SCHEMA_MISMATCH`、`MIGRATION_FAILED`、`GIT_NOT_INSTALLED`、`GIT_NOT_INITIALIZED`、`GIT_OPERATION_FAILED`、`GIT_NO_CHANGES`。
- 启动失败返回错误并由入口显示，不用 `panic` 伪装成功。
- 查询先判断错误，再判断结果是否存在。
- 创建流程中某一步失败直接返回，不用后续 `MkdirAll` 掩盖错误。

## 路径和进程

- 所有路径使用绝对路径并由 `paths` 包生成。
- 所有用户输入路径都做绝对路径和穿越检查。
- 子进程隐藏控制台窗口，停止时结束整个进程树。
- 网关只监听 `127.0.0.1`，不监听 `0.0.0.0`。
- Runner 目标不存在时返回真实错误，不伪造 PID 或日志。

## API 和事件

- Wails API 按 `ProjectAPI`、`SoftwareAPI`、`SystemAPI` 分组，方法名不重复模块名。
- DTO 字段与领域模型同名，不在 transport 层改名。
- 操作结果统一返回 `{ok, message}`。
- 事件载荷使用完整字段：`id`、`running`、`pid`、`state`、`message`。
- 修改绑定后执行 `wails generate module`。

## 测试

- 仓库测试使用临时目录中的真实 SQLite。
- 网关测试覆盖 Host、路径穿越、隐藏文件、PHP 回落、反向代理和 WebSocket。
- Runner 测试使用真实小进程覆盖启动、输出、状态和进程树结束。
- 依赖本机软件的测试找不到环境时跳过，并明确写出跳过原因。
