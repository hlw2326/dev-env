# 样式

令牌只在 `frontend/src/assets/css/style.css` 的 `:root` 里定义。组件只引用令牌,不写裸数值,不写回退值。

## 一、基本写法

- `<style scoped lang="scss">`,Tab 缩进,嵌套不超过 3 层。
- 类名短而有语义:`.header` `.body` `.item` `.label` `.desc` `.actions`。页面前缀只加在根节点。
- 每个区块上方一行注释:`/* 顶部工具栏 */`。
- 长度用 `rem`,1px 边框用 `px`。
- 过渡统一 `transition: all 0.15s ease`。
- 扁平风格:小圆角、1px 细边框、不加阴影。冷色调,Slate 灰蓝系。
- PrimeVue 的全局外观写进 `assets/css/primevue.css`,组件里必要时才用 `:deep()`。

## 二、颜色与间距

```scss
// 错:带回退值、写十六进制
background-color: var(--bg-card, #ffffff);
color: #16a34a;

// 对
background-color: var(--bg-card);
color: var(--ok);
```

- 只引用令牌:`--bg-app` `--bg-card` `--bg-sidebar` `--border-color` `--text-primary` `--text-secondary` `--text-muted` `--p-primary-color`。
- 状态色用 `--ok` `--warn` `--err` `--info`,亮色与暗色各定义一份。
- 圆角用 `--h-radius`,间距用 `--h-padding`。
- 颜色工具类 `.text-muted` `.text-ok` 与字号工具类 `.text-xs` `.text-sm` 只在 `style.css` 定义一份,组件里不重复定义。

## 三、字号

| 令牌 | px | 用途 |
|------|----|------|
| `--font-xs` | 12 | 辅助信息:元数据、徽标、时间、路径、代码、校验提示、统计标签 |
| `--font-sm` | 13 | 控件与次要正文:按钮、输入框、下拉、表格、导航项、页签、说明句 |
| `--font-base` | 14 | 正文与条目名称:列表行名称、区块小标题、Toast 标题 |
| `--font-lg` | 16 | 面板标题:卡片标题、弹窗标题、卡片主名称、空状态标题 |
| `--font-xl` | 18 | 页面标题 |
| `--font-2xl` | 24 | 数据大字:仪表盘统计数字 |

规则:

- 根字号 `html { font-size: 16px }`,`rem` 以此为基准。暗色主题不覆盖字号。
- 先判断元素的角色,再取对应令牌。不要按"看着差不多"自己选。
- 不存在 `--font-md`。
- **说明句与辅助信息**:一句完整的解释用 `sm`;键值对、徽标、状态、时间戳用 `xs`。
- **条目名称与控件文字**:作为内容展示的名称用 `base`;作为操作存在的按钮、选项用 `sm`。
- 层级靠字号和颜色区分,不靠字重。
- 需要新档位时,先改本文件,再改 `style.css`,不在组件里临时写数值。

## 四、图标

图标尺寸与文字阶梯分开,不为了图标大一点去改文字档位。

| 令牌 | px | 用途 |
|------|----|------|
| `--icon-xs` | 12 | 徽标内图标、勾选标记、折叠箭头、分组图标 |
| `--icon-sm` | 14 | 搜索框前缀图标 |
| `--icon-md` | 16 | 侧边栏导航图标 |
| `--icon-lg` | 20 | 色块里的图标:统计卡片、软件包、站点类型、警告提示、Toast |
| `--icon-2xl` | 40 | 空状态大图标 |

色块大小由 `width` 和 `height` 决定,不由图标字号决定。色块里的图标统一 20px。

## 五、字重、行高、字间距

- 所有文字 `font-weight: 400`。**不写 `font-weight`。**
- 行高只用令牌:`--leading-tight`(1.2,统计数字)、`--leading-snug`(1.4,Toast 与弹窗标题)、`--leading-normal`(1.5,正文,`body` 默认)。
- `body` 的 `letter-spacing: 0.3px` 是基准;`.font-mono` 为 0。其余不写 `letter-spacing`,按钮文字与正文一致。

## 六、PrimeVue 覆盖

| 组件 | 字号 |
|------|------|
| Button、InputText、Select 输入框本体 | `sm` |
| Tag | `xs` |
| DataTable 表头与单元格 | `sm` |
| Dialog 标题 | `lg` |
| Toast 标题 / 详情 | `base` / `sm` |
| Toast 图标 | `var(--icon-lg)` |

Select 下拉面板挂载到 `body`,默认继承正文字号。发现比输入框大时补:

```css
.p-select-overlay .p-select-option,
.p-confirmpopup .p-confirmpopup-message {
  font-size: var(--font-sm) !important;
}
```

## 自查

三条命令在 `frontend/src` 下都应该没有输出:

```bash
# 裸数值字号
rg 'font-size:\s*[0-9.]+(rem|px|em)' --glob '*.vue' --glob 'primevue.css' .
# 字重
rg 'font-weight:\s*(500|600|700|bold)' --glob '*.vue' --glob '*.css' .
# 已删除的令牌与回退值
rg 'font-md|var\(--[a-z0-9-]+,\s' .
```
