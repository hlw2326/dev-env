# 样式

- 令牌只在 `frontend/src/assets/css/style.css` 的 `:root` 定义。
- 组件只使用令牌：`--bg-app`、`--bg-card`、`--border-color`、`--text-primary`、`--text-secondary`、`--text-muted`、`--ok`、`--warn`、`--err`、`--info`、`--h-radius`、`--h-padding`、`--page-padding`。
- 页面正文内边距使用 `--page-padding`，组件之间的间距使用 `--h-padding`，两者不混用。
- 字号使用 `--font-xs`、`--font-sm`、`--font-base`、`--font-lg`、`--font-xl`、`--font-2xl`。
- 图标尺寸使用 `--icon-xs`、`--icon-sm`、`--icon-md`、`--icon-lg`、`--icon-2xl`。
- 样式使用 `<style scoped lang="scss">`，嵌套不超过三层。
- 类名短且有语义：`.header`、`.body`、`.list`、`.actions`、`.label`、`.meta`。
- PrimeVue 全局覆盖写在 `assets/css/primevue.css`，组件局部覆盖使用 `:deep()`。
- 按钮文字禁止换行；Flex 布局中的操作按钮不得被压缩。
- 长路径、日志和代码文本必须设置溢出策略，不能撑破容器。
- 页面默认不使用阴影；边框、冷色调和小圆角保持统一。
