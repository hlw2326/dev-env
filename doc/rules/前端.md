# 前端

- 技术栈固定为 Vue 3 `<script setup>`、TypeScript、PrimeVue、Pinia 和 Vue Router Hash 模式。
- 页面目录使用 `index.vue`、`use-xxx.ts`、`comps/` 的结构。
- 页面只负责组合组件和页面状态；业务请求放 `use-xxx.ts`，后端调用只放 `frontend/src/api/`。
- 页面和组件不得直接 import `wailsjs`，统一从 `@/api` 调用。
- 两个页面以上复用的组件提升到 `frontend/src/components/h-xxx`。
- 父子双向数据使用 `defineModel`，事件使用单个动词：`save`、`close`、`pick`。
- `v-for` 必须有稳定 `:key`；`v-if` 不与 `v-for` 放在同一标签。
- 不用三元表达式、`||`、`??` 或可选链实现兜底显示；用明确的 `v-if` / `v-else`。
- Boolean Prop 必须设置默认值；页面容器的 `padding` 和 `scroll` 默认开启。
- 页面正文滚动只放在 `h-page` 的 `.body`，不要在 `main-content` 或多个父级重复设置滚动。
- 前端错误必须显示后端返回的消息，不写空 catch。
- 单个 Vue 文件不超过 300 行，页面入口不超过 150 行；复杂区域拆到 `comps/`。
