# 前端字号规范

**适用：** `frontend/src` 下全部页面、组件与 PrimeVue 样式覆盖
**目标：** 同一种角色在任何页面都是同一个字号。组件里不再出现裸数值，只引用令牌。

---

## 一、现状问题

对 `frontend/src` 的 `font-size` 做了全量统计：39 个文件、156 处声明。

| 字号 | 声明次数 | 说明 |
|------|----------|------|
| `--font-xs` 12px | 65 | 最多 |
| `--font-sm` 13px | 50 | |
| `--font-base` 14px | 12 | 全局基准，但被显式声明的很少 |
| `--font-lg` 16px | 6 | |
| `--font-md` 15px | 2 | 与相邻两档只差 1px，肉眼分不出 |
| `--font-xl` 18px | 0 | 定义了，没人用 |
| 硬编码 | 21 | `0.9rem`、`0.8rem`、`1.1rem`、`1.2rem`、`1.3rem`、`1.4rem`、`2.5rem` 等 |

约四分之三的声明落在 12 到 13px。问题不在阶梯本身，而在**同一角色没有对应固定的档位**：

| 角色 | 现在的取值 |
|------|-----------|
| 卡片主名称 | 站点 16px、软件包 16px、服务实例 14px、仪表盘列表 14.4px |
| 区块小标题 | 详情面板 13px 加 500 字重，安装弹窗 13px 加 500 字重，运行环境分组名 14px |
| 页面标题与卡片标题 | 页面标题 16px，`h-card` 标题 15px，仪表盘卡片标题 16px，弹窗标题 14px |
| 空状态标题 | 都是 16px（唯一一致的） |
| 仪表盘统计数字 | 22.4px，不在任何档位上 |

另外还有三处会让界面显得不整齐：

1. 全局样式写了「字体不加粗」，但仍有 13 处 `font-weight: 500/600`。
2. `.text-xs`、`.text-sm`、`.text-muted`、`.text-ok` 在 5 个组件里各自重复定义了 9 份。
3. 图标尺寸也靠 `font-size` 控制，且有 `1.1rem`、`1.2rem`、`1.3rem`、`1.4rem` 四种相近值，对应的是同一类「色块里的图标」。

## 二、字号阶梯

根字号保持 `html { font-size: 16px }`，所有 `rem` 以 16px 为基准。令牌只在 `style.css` 的 `:root` 里定义，暗色主题不覆盖。

| 令牌 | rem | px | 用途 |
|------|-----|----|------|
| `--font-xs` | 0.75 | 12 | 辅助信息：元数据、徽标、时间、路径、代码、表单校验提示 |
| `--font-sm` | 0.8125 | 13 | 控件与次要正文：按钮、输入框、下拉、表格、导航项、标签、说明句 |
| `--font-base` | 0.875 | 14 | 正文与条目名称：列表行名称、区块小标题、Toast 标题 |
| `--font-lg` | 1 | 16 | 面板标题：卡片标题、弹窗标题、卡片主名称、空状态标题 |
| `--font-xl` | 1.125 | 18 | 页面标题 |
| `--font-2xl` | 1.5 | 24 | 数据大字：仪表盘统计数字（新增） |

调整：

- **删除 `--font-md`（15px）**。它只被 `h-card` 标题和侧边栏图标引用，分别并入 `lg` 和图标令牌。
- **启用 `--font-xl`**，用于页面标题，让页面标题和卡片标题拉开层级。
- **新增 `--font-2xl`**，承接现在 22.4px 的统计数字。

层级关系：同一屏里，页面标题 18 > 面板标题 16 > 正文与条目名称 14 > 控件与说明 13 > 辅助 12。相邻两档差 1 到 2px，因此**层级主要靠字号和颜色（`--text-primary`、`--text-secondary`、`--text-muted`）区分，不靠字重**。

## 三、角色与令牌对照

写新代码时，先判断元素属于哪个角色，再取对应令牌。不要按「看着差不多」自己选。

| 角色 | 令牌 | 示例 |
|------|------|------|
| 页面标题 | `xl` | `h-page` 的标题 |
| 面板标题 | `lg` | `h-card` 标题、弹窗标题、仪表盘卡片标题、日志面板标题 |
| 卡片主名称 | `lg` | 站点卡片名、软件包名、服务实例名、安装弹窗软件名 |
| 空状态标题 | `lg` | 各页面 `.empty-title` |
| 条目名称 | `base` | 列表行名称（仪表盘服务与站点、运行环境版本、分组名、版本号、任务消息） |
| 区块小标题 | `base` | 详情面板里的 `.sec-title` |
| 控件文字 | `sm` | 按钮、输入框、下拉、表格单元格、导航项、页签、单选项 |
| 说明句 | `sm` | 软件包简介、步骤说明、空状态副文案、警告说明 |
| 辅助信息 | `xs` | 元数据、徽标、时间、路径、版本号后缀、校验提示、代码区 |
| 统计大字 | `2xl` | 仪表盘统计数字 |
| 统计标签 | `xs` | 仪表盘统计下方的标签 |

两个容易混的判断：

- **说明句与辅助信息**：一句完整的解释（「该操作会……」）用 `sm`；键值对、徽标、状态、时间戳用 `xs`。
- **条目名称与控件文字**：作为「内容」展示的名称用 `base`；作为「操作」存在的按钮、选项用 `sm`。

## 四、图标尺寸

当前图标靠 `font-size` 控制，值零散。单独建一组图标令牌，与文字阶梯分开，避免「为了图标大一点去改文字档位」。

| 令牌 | rem | px | 用途 |
|------|-----|----|------|
| `--icon-xs` | 0.75 | 12 | 徽标内图标、勾选标记、折叠箭头、分组图标 |
| `--icon-sm` | 0.875 | 14 | 搜索框前缀图标 |
| `--icon-md` | 1 | 16 | 侧边栏导航图标 |
| `--icon-lg` | 1.25 | 20 | **色块里的图标**：统计卡片、软件包、站点类型、警告提示、Toast |
| `--icon-2xl` | 2.5 | 40 | 空状态大图标 |

「色块里的图标」不管色块是 36px、44px 还是 48px，图标统一 20px。色块大小由 `width` 和 `height` 决定，不由图标字号决定。

## 六、PrimeVue 组件

`assets/css/primevue.css` 已经覆盖了一部分，现状与目标：

| 组件 | 现在 | 目标 |
|------|------|------|
| Button | `sm` | 不变 |
| Tag | `xs` | 不变 |
| InputText、Select（输入框本体） | `sm` | 不变 |

**待核实：** Select 的下拉面板与选项、ConfirmPopup 的正文，没有出现在 `primevue.css` 里。PrimeVue 的下拉面板默认挂载到 `body`，可能继承正文字号而不是输入框的 `sm`。这一点我没有在运行中的界面里确认。建议实施时先打开一个下拉和一个确认气泡看一眼，如果比输入框字号大，再在 `primevue.css` 补：

```css
.p-select-overlay .p-select-option,
.p-confirmpopup .p-confirmpopup-message {
  font-size: var(--font-sm) !important;
}
```

确认没有差异就不用加。

## 九、约束与检查

项目目前没有配置 stylelint 或 eslint，所以靠命令检查。以下三条在迁移完成后都应该没有输出：

```bash
cd frontend/src

# 1. 组件里不允许出现裸数值字号（令牌定义在 style.css，html 的 16px 也在其中）
grep -rnE "font-size:\s*[0-9.]+(rem|px|em)" --include=*.vue --include=primevue.css .

# 2. 不允许非 400 字重
grep -rnE "font-weight:\s*(500|600|700|bold)" --include=*.vue --include=*.css .

# 3. 不允许再引用已删除的令牌
grep -rn "font-md" .
```

第 1 条会命中 `primevue.css` 里原来的 `1.2rem`，迁移后应当消失。

新代码的规则：

1. 字号只写 `var(--font-*)`，图标只写 `var(--icon-*)`，行高只写 `var(--leading-*)`。
2. 不写 `font-weight`。
3. 不在组件里重新定义 `.text-*` 工具类。
4. 需要一个新档位时，先改本文档第二节，再改 `style.css`，不在组件里临时写数值。

后续如果想自动化，可以加 stylelint 的 `declaration-property-value-allowed-list`，限制 `font-size` 只能取 `var(--font-*)`。现在没有这个依赖，先不加。
